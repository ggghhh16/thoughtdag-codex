# Markdown 阅读与分支追问

入口：桌面主窗口左下角的 **Markdown 阅读**。选择本地文件夹后，从文件列表打开章节。资料节点无需生成模型回答。

## 已实现

- 独立、可缩放的 Electron 阅读窗口；默认靠主窗口左侧，可以解除与恢复贴靠。主窗口移动、缩放及显示器变化时重新计算可见位置。空间不足时保留可访问的独立窗口。
- 复用现有 Markdown 渲染、资料节点、问答节点、流式生成、重试和右侧回答面板。支持相对图片、Markdown 章节链接及标题、代码、GFM 表格和公式。文件名、内容与教材无硬编码关系。
- 阅读选区与源码选区均使用原文件的 UTF-16 源码范围；处理重复句、跨段落、代码语法高亮、转义、实体及 Windows CRLF。代码部分选区自动引用整个代码块，同时保留实际选取范围。
- 每次教材提问创建独立根问题；同一选区可多次提问。荧光高亮及蓝色编号常驻；点击标记定位节点，同段多个问题通过选区旁的小列表选择。右键可编辑问题并在原节点重发，或删除当前标记；删除只隐藏教材标记，不删除节点、快照或回答，其他编号不变。文件选择、源码操作和标记管理收在可展开区域。问题及其后续回合均可返回原文。
- 阅读窗使用选区旁的“添加可选评论…”浮窗，右侧独立发送按钮；不填评论时默认请求解释选区。移除底部常驻输入、创建独立问题按钮、引用范围和额外引用选项，默认按选区及附近内容发送，超过 16,000 字符仍明确提示。已有小节/整章引用继续按历史快照重发；主动引用其他问题可通过主窗口现有连线功能完成。
- 新增 `sourceCitation` 资料关系记录范围和版本，排除普通父节点继承；资料节点保存整章不会导致该章自动加入问答上下文。
- 教材分支的每轮请求按显式画布连线和不可变引用快照重建，通过新的持久模型线程发送。不会复用可能带隐藏历史的线程，也不自动加入全局记忆；普通对话原有续接与 fork 行为保留。
- 原文身份、教材注册 ID、相对路径、SHA-256 版本、标题路径、源码范围、前后文字和提问时完整章节快照均随节点持久化。原文件变化后只在原文及前后证据唯一匹配时恢复，否则显示“原文已变化”，支持旧版本查看和手动重新关联。手动关联只改变返回位置，不改写历史引用。
- 源码保存写回当前本地文件，保留统一的 LF/CRLF 换行格式；先写临时文件、再次检查版本，再替换原文件。发现外部修改会拒绝覆盖，并保留编辑草稿。应用高亮、问题关系不插入 Markdown 正文。
- 主窗口是唯一画布状态写入方。阅读窗发送带操作 ID 和画布 ID 的命令，不启动画布恢复或持久化；重复操作 ID 只执行一次，过期画布请求被拒绝。关闭阅读窗不删除任何节点。
- 资料、标记、阅读位置、关系及原文快照通过现有 IndexedDB 和项目 JSON 导出/导入保存。原文件缺失仍可阅读保存内容，并重新选择文件夹恢复连接。

## 当前限制

- 独立窗口和本地文件编辑限桌面版；没有为网页端增加原生文件访问替代方案。
- 本轮模型交互使用可控 HTTP 模拟与既有适配层测试，没有发起真实模型生成；真实服务的配额及上下文上限仍可能导致生成失败，节点和引用会保留。
- 实际多显示器拔插未进行硬件验收；测试覆盖真实窗口贴靠、尺寸变化及包含负坐标/小屏幕的边界计算。
- 原文定位有意采用严格匹配。附近文字发生编辑也可能需要手动重新关联；不会猜测相似位置。公式生成的排版元素若不能得到源码范围，可在源码模式选择。
- UTF-8 Markdown 单文件上限 16 MB，单张本地图片上限 24 MB；超限明确报错。快照会增加项目备份体积。JSON 备份保留 Markdown 文本快照，不打包教材文件夹中的图片；图片文件缺失时仍可阅读文字引用。
- 外部改动在阅读窗重新获得焦点、主动刷新或保存时检查。保存使用乐观版本检查与原子替换，不提供跨外部编辑器的系统级写锁。
- 生成模式继续复用现有模型和工具设置；本轮没有扩展 PDF 阅读 UI，保留原实现，并验证其上下文传递回归。

## 章节导航与标题地图

- 主窗口入口、独立窗口标题和相关操作统一为“Markdown 阅读”。贴靠和字号按钮收在“窗口与字号”折叠项中。
- 左侧保留 44 px 导航栏：优先按二级标题（`##`）显示空心小圆点和连接线，悬浮时圆点略微放大并显示小字号标题，正文使用 `blur(2px)` 与 70% 不透明度实现适度模糊，移开恢复。没有二级标题时使用文中最浅层标题。
- 下方实心圆点展开章节地图，从底部滑入，默认高度为阅读窗的 30%，宽度接近正文；地图独立滚动，显示 H1–H6 节点和父子连线。点击跳转原文，支持关闭按钮、再次点击圆点、外部点击和 Escape 收起。
- 使用现有 Markdown AST 识别标题，支持行内格式、Setext 标题、跳级标题、重复标题、CRLF，排除代码块内的伪标题。定位使用实际源码偏移，不靠标题字符串猜测；正文更新和切换文件后重新生成。
- 验证：15 项测试、类型检查、ESLint 和生产构建通过；真实 Electron 验收涵盖设置收起展开、字号调整、章节圆点、模糊恢复、约 30% 高度与底部位置、分级地图和精确跳转，并通过原有框选提问与持久化回归。

## 居中导航、图标入口和英文界面

- 章节圆点在左侧栏上下居中，章节地图按钮固定在栏底部；章节过多时仍可滚动。
- 主画布以书本图标打开阅读器，位置在缩放加减按钮上方，标题和无障碍标签跟随语言。
- 阅读器界面、菜单、提示、引用范围、原文跳转、文件错误与原生文件夹对话框补充英文；已打开的阅读窗实时跟随主窗口语言切换，正文和用户问题保持原文。
- 15 项测试和真实双窗口验收通过，包括图标位置、导航居中、底部按钮、中英文切换、英文菜单及文件丢失提示。
