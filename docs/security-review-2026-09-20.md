## 已修复

| 问题 | 修复 |
| --- | --- |
| 后端只设置 CORS 响应头，未主动拒绝不可信来源；Host 未校验 | 只允许回环监听，校验 Host 和精确 Origin，拒绝跨站请求与非 JSON 提交 |
| 抓取 URL 校验 DNS 后，连接阶段再次解析 | 将已校验地址固定到实际连接，逐次重定向重新验证；增加 IPv6/保留地址处理 |

| fake-IP 网络兼容例外自动启用 | 改为受信任本机代理的显式配置，默认关闭 |
| 外部 MCP 实际默认开启，与配置文档不符 | 服务端改为 CODEX_ENABLE_MCP=true 才允许继承，仍需 UI 开关 |
| 原始 Markdown HTML 未做专门净化 | 加入 rehype-sanitize，保留公式、代码高亮与安全的任务列表 |
| HTML 资料可加载远程样式、图片等子资源 | 阅读框加入 CSP，阻止脚本、表单提交及远程资源加载 |
| 桌面 IPC 只检查 URL 来源 | 同时要求当前主窗口与主 frame，防止子 frame 访问桌面能力 |
| 脚本含个人绝对路径及 shell 字符串拼接 | 改为仓库相对位置、PATH/显式工具配置和参数数组 |
| 上游站点验证、旧首页 canonical/图片指向及赞助入口 | 移除本分支不适用的内容；上游研究页仍保留真实来源 |
| 忽略规则只覆盖 .env | 扩展到环境变体、认证状态、私钥和本地维护目录 |
